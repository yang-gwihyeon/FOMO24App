# 앱 용량 195 MB → 6.8 MB (Phosphor 제거 + Firestore SDK 제거 + 폰트 서브셋)

## 관찰
- App Store 표시 용량 194.9 MB (1.1). 기능 대비 과도.
- 도구: 기기용 Release 빌드 분해 (`du -sk`, `otool -L`), 서명 없는 빌드
  `xcodebuild build -configuration Release -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO`.
- 재현 절차: 위 빌드 → `Build/Products/Release-iphoneos/FOMO24.app` 하위 항목별 크기.

## 가설
1. Phosphor 아이콘 번들(9,108 imageset)이 대부분 (ADR-0008) — 확인됨 84.7 MB.
2. 남은 76 MB 중 Firestore gRPC 스택이 대부분 (ADR-0009) — 확인됨 50.1 MB + 바이너리 정적 링크분 약 15 MB.
3. Pretendard 4종 6 MB는 한글 전체 글리프 때문 — 확인됨 (전체 한글 유지 서브셋은 -18%뿐, 상용 2,350자 서브셋은 -73%).

## 선택지
ADR-0008, ADR-0009 참조 (각 3~6개).

## 결정
Phosphor → SVG 7개 로컬 / Firestore SDK → REST(URLSession) / 폰트 → KS X 1001 서브셋. 서버 무변경.

## 측정 (같은 Mac, Xcode 26.4, Release 기기 빌드, 서명 없음)
| 단계 | 앱 번들 | 바이너리 | 동적 프레임워크 | 폰트 | 자산 |
|---|---|---|---|---|---|
| 1.1 (Phosphor 포함, 기기 Debug) | 125 MB | — | — | 6.0 | 84.7 |
| ADR-0008 후 | 76 MB | 19.3 | 50.1 | 6.0 | 0.3 |
| **ADR-0009 후** | **6.8 MB** | **4.4** | **0** | **1.6** | 0.3 |

- App Store 표시 용량: 194.9 MB → (1.3 출시 후 App Store Connect 앱 크기 리포트로 기록)
- 기능 회귀: 강제 업데이트 실시간 반영 → 포그라운드 진입 시 반영. 그 외 없음 (REST 쓰기 규칙 통과 확인).

## 배운 것
- "용량"은 기능이 아니라 의존성이 결정한다. 아이콘 7개에 85 MB, 문서 get/set 3개에 50 MB.
- SDK 없이 REST로 충분한지의 판단 기준: 쿼리·실시간 구독·오프라인 쓰기 큐를 쓰는가. 셋 다 아니면 SDK는 비용만 낸다.
- 서버 타임스탬프·리스너처럼 SDK 전용 기능은 대체 시 "누가 그 값을 어디에 쓰는지"를 먼저 확인 (startedAt은 8.5h 판정에만).
