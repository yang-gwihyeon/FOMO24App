## 1. 노출: 메타데이터 (비용 0, 효과 최대) — 1주

애플 검색 순위는 **이름 · 부제 · 키워드 100자**만 본다. 설명은 순위에 안 잡힌다. 세 필드에 같은 단어를 반복하지 않는다.

| 필드 | 한국어 (자수) | 영어 (자수) |
|---|---|---|
| 이름 (30) | `FOMO24 - 해외주식 코인 실시간 시세` (23) | `FOMO24 - Stocks & Crypto Live` (29) |
| 부제 (30) | `24시간 선물 시세·다이나믹 아일랜드` (20) | `24/7 prices · Dynamic Island` (28) |
| 키워드 (100) | `엔비디아,테슬라,나스닥,미국주식,비트코인,선물,하이퍼리퀴드,바이낸스,위젯,잠금화면,수익률,알림,경제캘린더,FOMC,금리,환율` (69) | `nvidia,tesla,nasdaq,bitcoin,futures,hyperliquid,binance,widget,lockscreen,alerts,fomc,tokenized` (95) |

- 검색 의도 기준: 사람들은 "FOMO24"를 검색하지 않는다. **"엔비디아 주식", "비트코인 시세", "다이나믹 아일랜드 주식"** 을 검색한다. 이름·부제에 그 단어가 있어야 한다.
- 롱테일 우선: "해외주식 시세"는 증권사 앱과 경쟁 불가. **"다이나믹 아일랜드 주식", "하이퍼리퀴드", "토큰화 주식"** 은 경쟁이 거의 없고 이 앱만의 기능이다.
- 이름·부제는 **새 버전 제출 시에만** 변경 가능 → v1.3 제출과 함께.
- 한국어 현지화 추가: 이름·부제·키워드·설명·프로모션 텍스트·스크린샷 전부. 앱은 이미 한국어라 화면은 `-initialTab` 자동화로 뽑을 수 있다.

## 2. 전환: 제품 페이지 — 1주

- **스크린샷 순서**: 검색 결과에 첫 3장만 보인다. 1장은 "무엇을 해결하나"가 3초 안에 읽혀야 한다.
  1. 다이나믹 아일랜드·위젯·잠금화면 (이번에 갱신한 `05-everywhere`) — 유일한 차별점을 맨 앞으로
  2. 마켓 4거래소 비교
  3. 샀다 치고(FOMO) 수익률·알림
  4. 캘린더 5. 더보기
- 각 장 상단 카피를 **검색어와 일치**시킨다: "엔비디아·테슬라·비트코인 24시간 시세" 처럼. 스크린샷 텍스트는 순위엔 안 잡히지만 전환에 잡힌다.
- **평점 요청**: `SKStoreReviewController` 를 3번째 세션 또는 첫 FOMO 알림 도달 직후에 호출. 리뷰 0개 → 5개만 돼도 전환이 눈에 띄게 오른다. (코드 변경, 카드형 PR 1건)
- **프로모션 텍스트(170자)**: 심사 없이 수시 변경 가능. "FOMC 9/17 새벽 3시 · 캘린더에서 알림 받기" 처럼 이벤트 주간마다 바꾼다.
- **인앱 이벤트**: 무료 노출면. "FOMC 주간", "삼성 실적 주간" 같은 이벤트를 등록하면 검색 결과·투데이 탭에 카드가 뜬다. 캘린더 데이터가 이미 있으니 월 2회 운영 가능.

## 3. 유료: Apple Ads — 2주 실험

| | Basic | Advanced |
|---|---|---|
| 과금 | 설치당(CPI) | 탭당(CPT) |
| 최소 예산 | **월 $5,000** | 없음 |
| 결론 | 불가 | **이걸로** |

- 캠페인 1개, 한국 스토어, **검색 결과** 게재, 일 예산 ₩10,000(≈$7). 2주 = 약 ₩14만.
- 키워드 정확 일치 8~10개: `엔비디아 주식`, `테슬라 주가`, `비트코인 시세`, `나스닥 실시간`, `해외주식 시세`, `다이나믹 아일랜드 주식`, `주식 위젯`, `하이퍼리퀴드`. 브랜드 방어용 `fomo24` 1개.
- 벤치마크: 글로벌 CPT 중앙값 $0.92, CPI $1.80. 한국은 미국 대비 1.5배 저렴 → CPT $0.5~0.9 예상. 일 10~15탭, 설치 2~3건.
- **중단 기준(사전 결정)**: 2주 후 CPA > $3 이거나 설치 후 D7 유지율이 오가닉보다 낮으면 중단. 유입 경로별 유지율은 ASC "유지율"에서 본다.
- 커스텀 제품 페이지: "다이나믹 아일랜드" 키워드 광고는 05번 스크린샷이 1장인 페이지로 연결.
- 검색 탭 광고(검색창 아래 추천)는 CPT가 더 낮지만 의도가 약하다. 검색 결과가 먼저.

## 5. 실행 순서와 측정

```
주1  메타데이터(이름·부제·키워드 ko/en) + 한국어 현지화 + 스크린샷 순서 → v1.3 제출
주2  평점 요청 PR · 프로모션 텍스트 · 인앱 이벤트 1개 · 커뮤니티 포스트 2곳
주3~4  Apple Ads Advanced 2주 실험 (₩10,000/일)
주5  기준선 대비 측정 → 카드 작성
```

측정은 ASC 분석에서 **주 단위** 노출·조회·설치·전환·유입 경로(검색/브라우즈/광고/외부)를 표로 남긴다. 목표(가설): 4주 후 노출 761 → 3,000+, 설치 16 → 60+, 리뷰 0 → 5+.
