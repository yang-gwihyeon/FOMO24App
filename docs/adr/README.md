# Architecture Decision Records

아키텍처 수준 결정 하나당 파일 하나. 형식은 6칸 카드와 같다: 맥락(관찰) → 선택지 → 결정 → 근거 → 결과(측정) → 재검토 조건.
번호는 순차, 결정이 뒤집히면 새 ADR로 "supersedes" 표기. 면접에서 "왜 그렇게 했나요"에 대한 답이 곧 이 폴더다.
